# Product: Demo App

A basic Android application demonstrating a simple "Hello World" implementation. This is a starter template project with minimal functionality.

## Overview

- **Package Name**: com.example.demo
- **Minimum SDK**: 29 (Android 10)
- **Target SDK**: 36
- **Compile SDK**: 36
- **Language**: Kotlin
- **Architecture**: Single-activity with basic View-based UI

## Current State

This is a template project with:
- A single MainActivity
- Basic constraint layout with a TextView
- Standard Android app structure following modern best practices
- Edge-to-edge rendering enabled

## Purpose

Serves as a basic Android application template with Gradle-based build configuration and modern Android dependencies.
